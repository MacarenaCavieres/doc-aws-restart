## Descripción General

Este módulo abarca los fundamentos del lenguaje Python y su aplicación en la automatización de tareas, procesamiento de datos y administración de sistemas dentro del programa AWS re/Start.

## Resumen del Módulo

- **Fundamentos del Lenguaje:** Manejo de tipos de datos primarios, colecciones (listas, tuplas, diccionarios) y control de flujo mediante estructuras condicionales e iterativas.
- **Procesamiento de Datos:** Lectura/escritura de archivos CSV, manipulación de secuencias de texto, cálculos bioquímicos e implementación de algoritmos de cifrado (Cifrado César).
- **Administración de Sistemas y Debugging:** Automatización de comandos del sistema operativo (`os`, `subprocess`) y depuración interactiva en AWS Cloud9.
- **Desafío Práctico:** Desarrollo de un algoritmo dinámico para identificar y guardar números primos (del 1 al 250) en un archivo `.txt`.
